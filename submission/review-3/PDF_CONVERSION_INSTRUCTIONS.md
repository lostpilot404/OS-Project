# PDF Conversion Instructions

The Final Research Paper has been generated as both a DOCX and a PDF.

## Diagrams

All 7 technical diagrams are stored as **Mermaid source code blocks** (Courier New 8pt)
inside the DOCX/PDF. The PNG and SVG versions are still available in `diagrams/` for reference.

**To render the Mermaid diagrams** for a print-ready submission:
1. Open `diagrams/figures_mermaid.md` in any Markdown viewer that supports Mermaid
   (VS Code with Mermaid plugin, [mermaid.live](https://mermaid.live), Typora, Obsidian).
2. Export each rendered diagram as PNG/SVG.
3. Paste the rendered images back into the DOCX in place of the Mermaid code blocks.

Or: leave the Mermaid code blocks in the paper — many institutions accept this format.

## Method 1: Microsoft Word (Recommended)

1. Open `Final_Research_Paper.docx` in Microsoft Word
2. Review the document:
   - Generate Table of Contents: References > Table of Contents > Automatic Table 1
   - Add page numbers: Insert > Page Number > Bottom of Page
   - Check figure placement and table formatting
   - Fill in student information on the title page
3. Save as PDF: File > Save As > PDF

## Method 2: LibreOffice (Free)

1. Install LibreOffice from https://www.libreoffice.org/
2. Open `Final_Research_Paper.docx`
3. File > Export As > Export as PDF
4. Choose settings: 
   - Images: JPEG compression, 150 DPI
   - General: PDF/A-2b for archiving
   - Export

## Method 3: Google Docs

1. Upload `Final_Research_Paper.docx` to Google Drive
2. Open with Google Docs
3. File > Download > PDF Document

## Method 4: Online Converters (Use with caution)

- SmallPDF: https://smallpdf.com/word-to-pdf
- ILovePDF: https://www.ilovepdf.com/word_to_pdf

**Note:** Online converters may not preserve complex formatting. 
Always verify the PDF after conversion.

## Post-Conversion Checks

After generating the PDF, verify:
- [ ] All 22 sections are present
- [ ] All 7 figures are visible and legible
- [ ] Tables are not split across pages incorrectly
- [ ] Page numbers are correct
- [ ] Table of Contents links work (if applicable)
- [ ] Student information is filled in
- [ ] File size is reasonable (should be < 10 MB)
